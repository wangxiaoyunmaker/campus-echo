# Original main-scene wood deck shader, internal only
main-bridge-deck.mjs standalone browser ES module. woodenDeckPixel(u,v,width) -> packedRGBA. u cumulative native pixel arc distance, v signed perpendicular offset, width nativepixels. Original KG procedure and tt.plank palette retained, not newly drawn. Every5nativepixels a crosswise plank seam, border2pixels, deterministic grain/nails. renderWoodenDeck(length,width) is sample rectangle only, avoid stretching thisPNG across bent paths.

Map integration: use existing OSM bridge=yes centerlines ONLY. For each pixel within width/2 of centerline, project to nearest segment, u=sum(previous segment lengths)+localAlong, v=perpendicular; sample woodenDeckPixel, clip by measured bridge mask. Render above water/ground, below agents, maintain current passability. Wood appearance is an artistic surface choice, NOT evidence all Tongji OSM bridges are wooden. Limit to suitable small pedestrian bridges; don't convert car bridges into wood footbridges.

Source distinction: original site's kind boardwalk uses KG for full wood surface. Original kind bridge uses QG for outer parapet/edge THEN fills central deck with asphalt or footway materials (eK). Therefore this is the original WOOD BOARDWALK renderer available to apply to a wooden pedestrian bridge, not a falsely claimed universal original bridge sprite. originalBridgeEdgePixel also exported for native bridge edge treatment. Railings/shadow/actual structural elevation are not included here and must not be described as extracted. Do not fake moving block collisions for decorations.

Validated320x64 output decoded and visually checked. Module reads no network/files. 1texel=1nativeworldpixel. Keep same scene scale as character16x32. PNG is preview, not seamless tile. No public redistribution.
