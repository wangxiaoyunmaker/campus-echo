# JLU main-scene bicycle/e-bike shelter
Source: https://jlu.online/ deployed raster-_AffYBv6.js, raster.T.bikeshed / Bi.
Exported by running the original CPU pixel renderer in an isolated Node VM.
Original 96×50 canopy, support posts and parked vehicles preserved. Roof palette
changed from s.navy to s.green in the renderer to match the user's green-roof
reference. Three original seeded parking variants. No screenshot background.
Original attribution retained; reuse permission reported by project owner.
These are illustrative Tongji placements, not surveyed real charging facilities.
No claim of charging capability or live availability. Disable ?bikesheds=off.
